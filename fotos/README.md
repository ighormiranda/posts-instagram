## Regras

- **`estudio-moletom-verde/1744.jpg` não pode ser usada em post nenhum** — ele está com o olho meio piscando.
- Não repetir figurino parecido em intervalo curto. Alternar entre as pastas.
- O rosto dele precisa aparecer no perfil, mas não em toda capa: alternar com capas só de texto.

## Para subir foto nova

Pelo GitHub: **Add file → Upload files**, arrasta pra pasta certa e confirma. Funciona pelo celular.
